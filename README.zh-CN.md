# 抖音博主分析师

给 DesireCore 发一个抖音主页、作品链接或本地视频，即可开始整理证据、拆解内容和编写实拍练习。分析范围以能访问并核实的作品为准。

安装后默认启用博主研究、抖音视频下载和 Rea-Video。主页作品列表来自已授权的浏览器会话。下载技能处理用户有权保存的单条作品链接或视频 ID。用户提供的文件可以直接分析。

首次分析优先用巨章受管的 uv、Python 3.13 和 FFmpeg 套件，沿用执行环境已有的 Git。联网后，uv 会在隔离环境准备固定版本的 Rea-Video CLI 和 Python 依赖。分析时按需下载本地识别模型。视频默认本地分析。外部模型服务需另行配置和授权，可能另计费用。

原创智能体内容采用 MIT 许可。自带 Rea-Video 技能采用 Apache-2.0。见[第三方许可说明](THIRD_PARTY_NOTICES.md)和 [English README](README.md)。
