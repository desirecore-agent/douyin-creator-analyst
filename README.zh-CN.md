# 抖音博主分析师

给 DesireCore 发一个抖音主页、作品链接或本地视频，即可开始整理证据、拆解内容和编写实拍练习。分析范围以能访问并核实的作品为准。

安装智能体会默认启用 Rea-Video 和博主研究技能。首次运行由 uv 准备固定版本的 Rea-Video CLI。需要 uv、Git、FFmpeg 和 ffprobe、可写工作目录，以及首次下载依赖和识别模型的网络。视频默认本地分析。作品来源可以是已授权的浏览器会话或用户提供的文件。外部模型服务需另行配置和授权，可能另计费用。

原创智能体内容采用 MIT 许可。自带 Rea-Video 技能采用 Apache-2.0。见[第三方许可说明](THIRD_PARTY_NOTICES.md)和 [English README](README.md)。
